01 / The Project

Inside WezTerm

We are Arch Nemesis, a software architecture project group at Queen's University. Our project examines WezTerm, a terminal emulator and multiplexer.

Through conceptual analysis, source code investigation, and an enhancement proposal, we explore how the system is organized and how its components work together.
