01 / THE PROJECT

Inside WezTerm.

We are Arch Nemesis, a software architecture project group at Queen's University. Our project examines WezTerm, a terminal emulator and multiplexer.

Through conceptual analysis, source code investigation, and an enhancement proposal, we explore how its components are organized and how they work together.
